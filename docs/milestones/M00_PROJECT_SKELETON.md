# M00 - Project Skeleton

Goal: establish project structure and architectural boundaries.

## Scope

- choose and record the game engine decision: Godot 4.6.3 stable with GDScript
- responsive portrait/landscape canvas
- deterministic seeded RNG foundation
- asset conventions
- debug infrastructure
- simulation/presentation separation

## Success Criteria

- Engine decision is explicitly recorded with rationale.
- Project can launch a minimal empty shell in portrait and landscape.
- Simulation code can run independently from presentation code.
- Seeded RNG foundation exists and can be verified.
- Asset organization conventions are documented.
- Debug tooling exists where it materially helps verify deterministic gameplay.

## Non-Goals

- Full gameplay implementation.
- Networking.
- Monetization.
- Accounts.
- Backend systems.
- Final art.
