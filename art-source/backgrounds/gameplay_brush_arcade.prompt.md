# Gameplay Brush Arcade Background

The source master `gameplay_brush_arcade.png` was generated with the built-in OpenAI image-generation tool for the M7 gameplay-background proof.

## Production Prompt

Create a polished abstract Japanese arcade background with brush-painted energy and restrained Y2K anime personality. Use a deep charcoal-black and muted ink-green field with a quiet, low-noise central area for a tall mahjong board. Concentrate expressive dry-brush texture, subtle screen-print grain, sharp arcade accents, and hand-painted speed strokes around the perimeter. Use restrained crimson, cyan, and warm yellow accents. The portrait composition must also tolerate a landscape center crop.

Do not include text, logos, characters, mahjong tiles, icons, UI panels, borders, gradients, glow blobs, bokeh, watermarks, or a central focal point. Gameplay readability takes priority over decoration.

## Export

- Source master: `1024 x 1536` PNG.
- Runtime export: `768 x 1152` PNG using high-quality bicubic downsampling.
- Godot presentation: aspect-covered, centered crop with a subtle dark wash.
