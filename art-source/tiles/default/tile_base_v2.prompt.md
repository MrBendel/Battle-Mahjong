# Default Tile Base V2 Generation Notes

Generated with OpenAI image generation using the prior portrait and landscape tile masters plus the gameplay tile-stack inspiration as visual references.

## Prompt

Create a single blank portrait mahjong tile base as a transparent PNG asset for a 2D mobile game. Match the gameplay inspiration's illustrated physical style: tall upright proportions, warm ivory ceramic front, subtly imperfect inked dark-brown outer contour, gently rounded corners, a compact golden-brown lower sidewall, restrained bevel and highlight, and very light paper/ceramic texture. Keep the face completely blank for composited artwork. Do not include symbols, corner scuffs, wear marks, decorative notches, background, floor, or a baked cast shadow. Center the tile and preserve generous transparent padding without cropping its contour. The result should feel hand-illustrated and arcade-like rather than glossy, photorealistic, or toy-like.

The generated master was resized to the skin's canonical `512 x 736` source geometry. Runtime export is generated at `256 x 368` by `scripts/tools/export_tile_art.gd`.
