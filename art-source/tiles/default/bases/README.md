# Default Ceramic Base Masters

The portrait and landscape PNG files in this directory are transparent high-resolution masters derived from artwork supplied for the first Default skin pass. Runtime exports are generated at 50% scale under `game-assets/tiles/default/bases/` by `scripts/tools/export_tile_art.gd`.

The image-edit prompts used the supplied tall or wide tile as the exact edit target, removed only the black surrounding background, preserved the ceramic silhouette, glaze, wear marks, depth, proportions, and blank face, and prohibited symbols, text, logos, watermarks, extra objects, or cropped edges.

Portrait and landscape are separate presentation variants of the same cosmetic skin. They do not define gameplay identity or board occupancy.
